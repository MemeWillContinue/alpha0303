API Endpoints ​

1. Create Payment Link ​

POST /api/v1/payments

Creates a new on-chain payment request.

Request Body ​

json
{
  "merchant_order_id": "ORDER-20260221-001",
  "amount": "100.00",
  "asset": "USDT",
  "chain": "ERC20",
  "callback_url": "https://merchant.com/payment/callback"
}

Parameters ​

FieldTypeRequiredDescription
merchant_order_idstringOptionalYour internal order ID
amountstringRequiredPayment amount in USDT/USDC
assetstringRequiredUSDT or USDC
chainstringRequired"Ethereum", "BNB Smart Chain", "Solana"
callback_urlstringOptionalWe will send the payment result here

Success Response ​

json
{
  "payment_id": "pay_9a7ffd02a",
  "merchant_order_id": "ORDER-20260221-001",
  "amount": "100.00",
  "asset": "USDT",
  "chain": "ERC20",
  "expires_at": "2026-02-21T21:42:00Z",
  "pay_address": "0x31dA3c98f...",
  "payment_url": "https://pay.pinkwallet.com/p/pay_9a7ffd02a",
  "qrcode_url": "https://pay.pinkwallet.com/p/pay_9a7ffd02a/qrcode.png"
}

Example QR Code Usage ​

You can embed our hosted QR code:

html
<img src="https://pay.pinkwallet.com/p/pay_9a7ffd02a/qrcode.png" width="220" />

Or generate your own QR code using the returned payment address.

2. Get Payment Status ​

GET /api/v1/payments/{payment_id}

Retrieve an existing payment status.

Response ​

json
{
  "payment_id": "pay_9a7ffd02a",
  "status": "pending",
  "amount": "100.00",
  "asset": "USDT",
  "chain": "ERC20",
  "pay_address": "0x31dA3c98f...",
  "expires_at": "2026-02-21T21:42:00Z",
  "paid_at": null,
  "tx_hash": null
}

Statuses ​

  • pending
  • paid
  • expired
  • failed
