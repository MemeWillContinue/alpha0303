# 三、VA（Virtual Account）虚拟账户体系

## 3.1 概述

VA（虚拟账户）用于为用户或商户分配独立资金标识：

- **收款与充值**：接收链上资金
- **资金归集**：集中管理多来源资金
- **子账户管理**：支持层级账户结构

---

## 3.2 VA 模型设计

支持两种模式：

### 1️⃣ 独立地址模式

每个用户对应独立链上地址。

### 2️⃣ 归集地址 + Memo 模式

共享主地址，通过 Memo 区分用户。

```json
{
  "va_id": "VA_10001",
  "master_address": "TMASTER",
  "memo": "123456"
}
```
